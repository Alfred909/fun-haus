About this model

A simplified, rule-based ecology, not a validated recreation of a real pond. Time, lifespans and reproduction are compressed.

Plants use light, water and soil nutrients. Insects eat plants; frogs eat insects; herons eat frogs. Death returns nutrients. Animals choose between feeding, fleeing, resting and exploring using local information.

Sense mode is a top-down abstraction of detection range, not literal animal eyesight. Plants do not see. Each browser runs its own world, only while this page is active; reopening starts a new ecology.

Population ceilings keep the prototype responsive. There is no automatic replacement after extinction.
